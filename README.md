# 토익 Part 5 · 10문제 퀴즈

토익 Part 5 스타일 10문제를 한 카드에서 넘기며 풀고, 보기를 고르는 즉시 채점·해설을 보는 웹앱입니다.
`https://calclex.com/listening/` 에서 바로 열 수 있습니다(휴대폰 홈 화면에 추가해도 됩니다).

## 들어 있는 것

- **100문제 = 10세트 × 10문제** — 품사·어미, 시제·태, 수일치, 접속사 vs 전치사, 관계사·분사, 대명사·수량, 비교·가정법, 비즈니스 어휘를 세트마다 골고루 배치
- **즉시 채점** — 정답 보기에는 초록 원, 고른 오답에는 빨간 원, 두 보기 모두 "왜 그런지" 한국어 해설. 나머지 보기는 흐리게
- **힌트(💡) / 문항 이동(🗂️)** — 힌트는 필요할 때만 펼치고, 문항 번호로 바로 점프
- **세트 결과** — 점수, 문항별 ○/× 해설 다시 보기, 누적 약점 파트(정답률 낮은 순)
- **다음 문제 풀기** — 이 버튼을 눌러야만 새 10문제 세트로 넘어갑니다. 10세트를 다 풀면 처음부터 다시 돌면서 기록은 계속 쌓입니다
- **노션 정리용 리포트** — 누적 문항·정답률·유형별 정답률·주요 오답 패턴을 한 번에 복사. 노션 `NOTE` 하단 정리에 이어 붙일 때 쓰는 요청문이 함께 들어 있습니다

## 문제에 대해

실제 ETS 기출 원문을 그대로 옮긴 것이 아니라, ETS Part 5의 **출제 영역·보기 함정 구조·빈출 어휘**에 맞춰 새로 쓴 문제입니다.
문항마다 4개 보기 모두에 정답/오답 이유를 달았고, 빌드 단계에서 중복·해설 누락·정답 위치 쏠림을 자동 검증합니다.

## 저장 방식

풀이 기록과 현재 세트는 브라우저 `localStorage`(`toeicP5.v1`)에만 저장됩니다. 서버로 보내는 데이터는 없습니다.
기록을 지우려면 브라우저 개발자 도구에서 해당 키를 삭제하거나 사이트 데이터를 지우면 됩니다.
