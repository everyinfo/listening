# 리스닝 (개인용 음악 앱)

폰에 있는 mp3를 아이폰에서 바로 듣는 웹앱(PWA)입니다. 구간 반복(A-B), 0.25~2배속, 두 번 탭 되감기(10초 또는 한 문장), 플레이리스트, 원곡 가사(LRCLIB), 오프라인 실행을 지원합니다.

## GitHub Pages로 올리기 (처음 한 번)

1. GitHub에서 새 저장소를 만듭니다. 이름은 예: `listening`, 공개(Public)로 만듭니다.
2. 이 폴더 안의 파일을 전부(폴더 구조 그대로) 저장소에 올립니다. 웹에서 `Add file > Upload files`로 폴더째 끌어다 놓으면 됩니다.
   올려야 할 것: `index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/`
3. 저장소 `Settings > Pages`에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
4. 1~2분 뒤 `https://내아이디.github.io/listening/` 주소가 생깁니다.
5. 아이폰 사파리로 그 주소를 열고 공유 버튼 > `홈 화면에 추가`를 누릅니다.
6. 홈 화면의 아이콘으로 앱을 연 뒤, 인터넷이 켜진 상태에서 한 번 완전히 로드되게 두면 이후 오프라인(비행기 모드)에서도 실행됩니다.

올라가는 것은 앱 코드뿐이고, mp3와 플레이리스트는 폰 안에만 저장됩니다.

## 앱 코드를 고쳤을 때

`sw.js` 맨 위의 `listening-v1.0.0` 숫자를 올려서 같이 올려 주세요. 안 올리면 폰이 예전 파일을 계속 씁니다. 올린 뒤 앱을 완전히 종료했다가 두 번 열면 새 버전이 적용됩니다.

## 곡 넣기

앱의 `곡` 탭 오른쪽 위 `+` 버튼 > `파일` 앱에서 mp3 선택(여러 개 가능). 곡은 앱 안에 복사되어 보관되므로 폰 용량을 원본과 합쳐 두 배 씁니다.

## 백업

`설정 > 플레이리스트와 가사 내보내기`로 JSON 파일을 저장해 두세요. 곡 파일은 포함되지 않으며, 같은 mp3를 다시 불러오면 플레이리스트가 이어집니다.
